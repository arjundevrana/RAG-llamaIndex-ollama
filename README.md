# LlamaIndex Ollama Demo

Rag_Deep_Div_Architeuctre.png

A small TypeScript example that uses LlamaIndex with local Ollama models. The application creates a vector index from a text document, searches the relevant document chunks, and generates an answer locally.

This integration does not require an OpenAI API key or OpenAI credits.

## How It Works

1. Ollama creates embeddings for the document with `nomic-embed-text`.
2. `VectorStoreIndex` stores the document vectors in memory.
3. The query engine retrieves the most relevant chunks.
4. Ollama generates an answer with `llama3.2`.
5. The script prints the answer and the retrieved source nodes.

## Prerequisites

Install the following software:

- Node.js 18 or newer
- npm
- Ollama

### Install Ollama on macOS

Using Homebrew:

```bash
brew install ollama
```

Alternatively, install Ollama from the official website:

<https://ollama.com/download/mac>

Confirm the installation:

```bash
ollama --version
```

## Install Project Dependencies

From the project directory:

```bash
cd /Users/yogi/Documents/lamaIndex-Demo-AI/LlamaIndex-Demo
npm install
```

The important packages are:

- `llamaindex`: indexing and query engine APIs
- `@llamaindex/ollama`: Ollama chat and embedding adapters
- `typescript`: TypeScript compiler
- `tsx`: TypeScript runner used to execute the example

## Start Ollama

Ollama must be running before the example starts. On macOS, opening the Ollama application usually starts the local service. You can also run:

```bash
ollama serve
```

The default Ollama endpoint is:

```text
http://127.0.0.1:11434
```

## Download the Required Models

Download the embedding model:

```bash
ollama pull nomic-embed-text
```

Download the chat model:

```bash
ollama pull llama3.2
```

Check that both models are installed:

```bash
ollama list
```

The list should contain entries similar to:

```text
nomic-embed-text:latest
llama3.2:latest
```

The chat model is approximately 2 GB, so the download may take several minutes.

## Run the Example

Run the TypeScript file with:

```bash
npx tsx example.ts
```

The output contains:

- The answer generated by `llama3.2`
- The retrieved source text
- Similarity scores for the source nodes
- Source metadata

## Model Configuration

The defaults are defined in `example.ts`:

```typescript
Settings.embedModel = new OllamaEmbedding({
    model: process.env.OLLAMA_EMBED_MODEL ?? "nomic-embed-text",
});

Settings.llm = new Ollama({
    model: process.env.OLLAMA_CHAT_MODEL ?? "llama3.2",
});
```

You can use different locally installed models without editing the source:

```bash
OLLAMA_EMBED_MODEL=nomic-embed-text \
OLLAMA_CHAT_MODEL=llama3.2 \
npx tsx example.ts
```

For a different model, pull it first and then set the matching variable. For example:

```bash
ollama pull gemma3
OLLAMA_CHAT_MODEL=gemma3 npx tsx example.ts
```

The embedding model must support Ollama embeddings. Keep the embedding model consistent when creating and querying an index.

## Change the Question

Edit the query in `example.ts`:

```typescript
const { message, sourceNodes } = await queryEngine.query({
    query: "What does the author do in the college?",
});
```

Then run the example again:

```bash
npx tsx example.ts
```

The current sample reads this file from the installed package:

```text
node_modules/llamaindex/examples/abramov.txt
```

To use your own text file, replace the `path` value with a path to that file.

## Troubleshooting

### `model 'llama3.2' not found`

The chat model has not been downloaded, or its name does not match the configured value. Run:

```bash
ollama pull llama3.2
ollama list
```

If you use another model, set `OLLAMA_CHAT_MODEL` to its exact name.

### `model 'nomic-embed-text' not found`

Download the embedding model:

```bash
ollama pull nomic-embed-text
```

### Ollama connection errors

Make sure Ollama is running and test the service:

```bash
ollama list
```

If the command cannot connect, start Ollama with:

```bash
ollama serve
```

### OpenAI `429 insufficient_quota`

This example is configured for Ollama and should not call OpenAI. If an OpenAI API key is present in an old `.env` file, it is not needed for this version. Never commit API keys to the repository. Revoke any key that has been exposed and remove it from `.env`.

### TypeScript cannot find `process`, `console`, or `node:fs/promises`

Install the Node.js type definitions:

```bash
npm install --save-dev @types/node
```

Then confirm that `tsconfig.json` contains:

```json
{
    "compilerOptions": {
        "types": ["node"]
    }
}
```

## Notes

- The vector index is created in memory each time the script runs.
- The first request can be slower while Ollama loads a model.
- No cloud API request is needed for embeddings or answer generation.
- Larger chat models generally produce better answers but require more disk space and memory.
